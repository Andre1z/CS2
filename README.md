# CS2 Inventory

Web para visualizar y valorar inventarios de Counter-Strike 2.

## Tecnologías

- PHP 8.1+
- MySQL
- HTML
- CSS
- JavaScript
- Steam OpenID

## Instalación

Instalar dependencias:

composer install

Regenerar autoload:

composer dump-autoload

Configurar `.env`.

Iniciar servidor:

php -S localhost:8000 -t public

Abrir en el navegador:

http://localhost:8000
